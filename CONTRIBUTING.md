# Contributing

Thanks for contributing to **dropafile**.

## Setup

```bash
git clone https://github.com/dropafile/dropafile.git
cd dropafile
```

## Pull requests

1. Branch from `main`.
2. Open a pull request with a clear summary and test plan.
