# About this folder

Adopter files with placeholders (`owner-username`, `repo-name`, `author-display-name`, …). Copied to the repo root by `./scripts/init-from-template.sh`.

| Template file | Destination |
|---------------|-------------|
| `README.md` | Root README |
| `INSTRUCTIONS.md` | Root INSTRUCTIONS |
| `package.json` | Root package.json |
| `wrangler.toml` | Root wrangler.toml |
| `index.html` | Root index.html |
| `LICENSE`, `CHANGELOG.md`, … | Root (via common manifest) |

See [docs/INIT_TEMPLATE.md](../docs/INIT_TEMPLATE.md).
